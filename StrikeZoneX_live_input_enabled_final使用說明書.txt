
【StrikeZoneX 即時輔助系統 - 最終版主程式使用說明書】
版本：StrikeZoneX_live_input_enabled_final.py

——————————————
一、系統定位
——————————————
本程式為「即時交易輔助系統」，負責即時監控使用者輸入的股票，根據支撐與壓力價格、自訂停損停利、成交條件、自動快照與大盤判斷等邏輯，提供盤中交易決策輔助。

系統由以下功能模組構成：
A：登入模組（SK API 登入與事件註冊）
B：進出場條件判斷（支撐/壓力 ±0.5%，3 秒內成交）
C：基礎假訊號過濾（進場連續 2 Tick 觸價）
D：風控模組（停損 -1%，停利 +2%，13:00 強制平倉）
F1~F3：即時快照模組（F8 觸發，輸出所有股票資訊）
F4：多股比較模組（選出主力最強、漲幅最大、觸價股）
F5：大盤即時資訊接收與共振判斷（加權指數 tse01）

——————————————
二、啟動步驟
——————————————
1. 雙擊執行程式 `StrikeZoneX_live_input_enabled_final.py`
2. 輸入你今天要監控的股票與支撐壓力區（格式如下）：
   範例：
     → 2330 598 602
     → 8222 125 128
     → done

3. 系統會自動執行：
   - 登入群益 API
   - 訂閱每支股票的 Tick（逐筆資料）
   - 訂閱加權指數 tse01 報價（接收大盤資訊）
   - 啟動即時資料監控

4. 執行後畫面會顯示：
   - `✅ 已訂閱 2330`
   - `▶️ 即時監控開始，按 Ctrl+C 中止`

——————————————
三、進出場判斷邏輯
——————————————
【進場條件】
- 當前 Tick 價格連續兩筆落在支撐區（或壓力區） ±0.5%
- 在進場觸價後 3 秒內成交有效
- 以第 2 筆 Tick 價格作為模擬成交價

【出場條件】
- 達停利（+2%）或停損（-1%）即出場
- 每日 13:00 前無論盈虧強制平倉

——————————————
四、快照功能（F1~F4 整合）
——————————————
按下 F8 即可觸發「快照模組」，將以下資訊儲存成 JSON 檔案：

1. 每支股票資訊（你手動輸入的標的）：
   - 股票代碼、目前價格、支撐與壓力
   - 是否落在支撐/壓力區
   - 是否持倉、進場價格與時間、理由
   - 是否觸發停利/停損
   - 主力分數（暫用假分數，未來可強化）
   - 系統建議：「觀望 / 可考慮進場 / 持有觀察」

2. 大盤資訊（加權指數 tse01）：
   - 即時價格、漲跌幅、是否創高（與開盤後最高價比較）

3. 多股比較（F4 模組）：
   - 主力最強的股票代碼（分數最高）
   - 漲幅最大的股票代碼（今日漲幅最大）
   - 當前正觸價的股票清單

4. 儲存位置：`/snapshot/f8_YYYYMMDD_HHMMSS.json`

5. 每次成功快照會：
   - 終端顯示儲存成功訊息
   - 跳出 Windows 系統通知：「快照已儲存」

——————————————
五、附註與擴充
——————————————
- 系統目前支援多支股票同時監控
- Tick 數據來源為 SK API 的 `GetStockByIndex`
- 如需未來整合 AI 判斷、圖形化操作、主力真實分數計算，可再擴充模組

——————————————
六、注意事項
——————————————
- 請確認執行時段為開盤時（平日 09:00～13:30），否則無 Tick
- 若按 F8 無反應，請確認是否已有 Tick 資料出現
- 若輸入錯誤格式，請重新執行程式
