TickRecorder 使用說明書（版本 1.0）
====================================

📦 模組名稱：
TickRecorder（獨立模組）

🧠 功能簡介：
本模組用於記錄群益 API 中的即時 Tick 資料，並於每日收盤（13:30）自動儲存為 JSON 檔案。
程式支援開盤前啟動，會自動等到 09:00 開始記錄，並支援中途斷線保護（Ctrl+C 中斷仍會自動存檔）。

✅ 適用場景：
- 沒有歷史 Tick 權限，但希望自行建立逐筆資料庫
- 即時交易策略驗證與後續參數優化分析
- 可搭配 StrikeZoneX 主控系統使用，或獨立運作

🚀 執行方式：
請執行 `tick_recorder_main.py`，依照指示輸入股票代號：

範例輸入：
2330,2603,8222

系統回覆：
已確認 2330,2603,8222 成功新增

🕒 程式流程：
1. 輸入股票代號
2. 若早於 09:00 則等待開盤
3. 09:00 ~ 13:30 間自動記錄 Tick 資料
4. 每 30 分鐘主動回報系統穩定運行
5. 收盤後自動儲存 JSON 檔案至 ticks/ 資料夾中
6. 若期間斷線或程式中斷，仍會自動存檔

📁 輸出範例檔案：
./ticks/20250421_2330.json
./ticks/20250421_2603.json

📄 JSON 檔案格式（單筆資料）：
{
  "time": "09:05:32.123",
  "price": 130.5,
  "volume": 3,
  "bid": 130.0,
  "ask": 131.0
}

🛡 中斷保護：
如執行中按下 Ctrl+C，中斷時會立即儲存所有資料，不會遺失。

💬 注意事項：
- 本模組不參與任何進場策略判斷，僅負責資料收集
- 請確保你的 API 登入與報價監控成功，否則不會有資料進來
- 檔案儲存為 UTF-8 編碼格式

👨‍💻 開發者備註：
- 未來可擴充儲存格式為 CSV / SQLite
- 可搭配 replay_tick 模擬器進行策略驗證
