StrikeZoneX_realtime_mode.py 使用說明書

版本：v1.0
作者：Leo & ChatGPT
日期：2025-04-21

=======================================
【一、程式簡介】
StrikeZoneX_realtime_mode.py 為 StrikeZoneX 系統的模擬模式主控程式。
可針對多支股票自動登入、取得指定日期的歷史 Tick 資料，並執行支撐 / 壓力策略模擬。
每支股票的交易結果會印出於終端機中，用於盤後模擬分析與策略測試。

=======================================
【二、操作說明】
1. 編輯參數：
   - 可於程式中設定股票清單 `stock_ids`
   - 在 `support_resistance_map` 中設定每支股票的支撐與壓力價位
   - 日期自動抓當天日期，可手動修改為任意模擬日

2. 執行程式：
   使用命令列輸入：
   python StrikeZoneX_realtime_mode.py

3. 程式會自動完成：
   - 登入群益 API
   - 擷取每支股票的 Tick 資料
   - 執行模擬（模組 B）
   - 印出每筆模擬結果

=======================================
【三、模擬邏輯說明】

模組 B - 支撐壓力策略模擬邏輯：
- 觸價條件：連續兩筆 Tick 落在支撐或壓力 ±0.5% 範圍內
- 成交條件：觸價後 3 秒內需再次出現相同區間價格，才視為進場成功
- 出場條件：
  - 停損：-1.0%
  - 停利：+2.0%
  - 強制平倉時間：13:00

=======================================
【四、模擬結果輸出】

結果會直接輸出於終端機，每筆交易紀錄包含：
- 進場時間、進場價格、方向、理由
- 出場時間、出場價格、理由
- 損益金額、持倉時間

若當天無符合進出場條件，將顯示「⚠️ 無交易結果」

=======================================
【五、注意事項】
- 此程式為「模擬模式」，使用歷史 Tick，不具即時接收能力
- 使用模組為 simulate_support_resistance.py 中的 simulate_strategy()
- 請確認登入帳號有歷史 Tick 權限
- 輸出僅於終端機中顯示，無自動存檔（可另行加上 json / Excel 輸出）
