StrikeZoneX_live_input_enabled.py 使用說明書

版本：v1.1
作者：Leo & ChatGPT
日期：2025-04-21

=======================================
【一、程式簡介】
此版本為 StrikeZoneX 系統的即時模式主控程式（含支撐/壓力邏輯 + 即時 Tick 監控）。
新增輸入介面，支援使用者手動輸入欲監控的股票與其支撐、壓力價位，程式將自動訂閱報價並進行交易判斷。

=======================================
【二、操作說明】
1. 啟動方式：
   使用命令列執行：
   python StrikeZoneX_live_input_enabled.py

2. 輸入股票與價位：
   程式啟動後，依照提示輸入格式：
   股票代碼 支撐價 壓力價
   （例如）→ 2330 598 602
   輸入完畢後輸入：done

3. 程式會顯示：
   ✅ 已確認 2330, 8222 成功新增

4. 開始即時監控：
   - 自動登入群益 API 並訂閱所有輸入股票
   - 即時接收 Tick 並自動進場、出場
   - 每筆出場會立即印出該單損益
   - 結束程式時（Ctrl+C）將自動儲存交易結果

=======================================
【三、判斷邏輯說明】

【進場條件 - B模組】
- 兩筆連續 Tick 均落於支撐 / 壓力 ±0.5% 區間
- 且 3 秒內再次出現同區間價格才算進場成功

【出場條件 - D模組】
- 停損：價格反向超過 -1.0%
- 停利：價格順向超過 +2.0%
- 強制平倉：13:00 時無條件平倉所有持倉
- 單股單筆持倉：同一支股票僅可持有一單

【出場時回饋】
- 每筆出場都會立即於終端顯示出場理由與損益金額
- 例：✅ 出場：停利，損益 +2000

=======================================
【四、輸出資料】
- 每筆交易結果自動儲存於：
  report/realtime_YYYYMMDD.json

- 包含欄位：
  股票代碼、進出場時間與價格、方向、理由、損益、持倉時間

=======================================
【五、其他備註】
- Recorder 模組未整合，需另啟動 recorder.py
- 若 Tick 無資料，請確認登入成功與訂閱是否正常
- 後續可新增 GUI 輸入介面、Excel 批次輸入、快照模組等擴充功能
